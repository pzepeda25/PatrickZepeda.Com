## 2025-01-20 - Expensive React Re-renders During Global Scroll State
**Learning:** `App.tsx` has an `activeNavSection` state that updates on window scroll to highlight the current navigation link. Every scroll event triggers a re-render of `App.tsx` and all of its children, which includes extremely heavy components like `ScannerCardStream` (Three.js WebGL scene) and `CardStack` (complex motion animations). This caused significant frame drops and stuttering while scrolling.
**Action:** When a parent component holds global scroll/mouse state, ensure all expensive children (especially those containing WebGL, heavy DOM nodes, or complex animations) are wrapped in `React.memo()`. This breaks the render chain and prevents `App.tsx` from needlessly re-rendering components whose props haven't changed.
