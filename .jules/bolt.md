## 2024-05-23 - Memoize Heavy Components to Prevent Expensive Re-renders
**Learning:** The application tracks its active scroll state (`activeNavSection`) at the root `App.tsx` level, which means that any time the user scrolls and the nav section changes, the entire `App` component re-renders. This cascades down to all child components, including very heavy components like `MediumFeed`, `FeaturedProject`, and `YouTubeLatestVideos` (and the underlying `ScannerCardStream` which spins up a Three.js scene).
**Action:** Always memoize heavy components (especially those involving canvas, WebGL/Three.js, or complex animations) using `React.memo` when they rely on props that don't change frequently or don't take any props but are situated under components with fast-changing state like scroll handlers.
