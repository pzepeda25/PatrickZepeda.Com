## 2024-03-05 - Root State Thrashing App-Wide Renders
**Learning:** Found a major performance bottleneck where the root App.tsx tracks scroll state continuously using `activeNavSection`, updating on every scroll event via intersection logic. This root state change cascades down to every child component. Normally this is manageable, but components running heavy 3D canvases, external API feeds, or complex physics (like `FeaturedProject`, `MediumFeed`, and `YouTubeLatestVideos`) were suffering severe jitter because they were re-rendering on nearly every pixel scrolled.
**Action:** Always verify if a root component is tracking scroll or mouse position. If so, immediately check if heavy downstream UI blocks are memoized. Wrapped these heavy components in `React.memo()` to isolate them from the root's scroll-spy state updates.
