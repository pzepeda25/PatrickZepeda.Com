## 2026-05-01 - Heavy Unmemoized Children + Scroll Spying Anti-Pattern
**Learning:** Found a specific codebase architecture pattern in this React frontend: The root `App.tsx` has a scroll listener that continually updates an `activeNavSection` state as the user scrolls. This causes the entire `App` component and all its children to re-render repeatedly during scrolling. This is especially problematic for components rendering WebGL/Three.js canvases (like `ScannerCardStream` inside `MediumFeed`) and other heavy UI elements (`FeaturedProject`, `YouTubeLatestVideos`) which don't depend on the scroll state.
**Action:** Always wrap heavy child components (especially those using Three.js or complex animations) in `React.memo()` if their parent components update state frequently on events like scroll or mousemove.
